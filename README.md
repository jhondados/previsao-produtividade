# 🌱 Previsão de Produtividade

> Previsão de produtividade por talhão com IA. Combina histórico, manejo e dados ambientais para estimar a colheita com precisão.

**🌐 Demo ao vivo (web app interativo):** https://jhondados.github.io/previsao-produtividade/

[![Vertical](https://img.shields.io/badge/Vertical-Agro-blue)]() [![IA](https://img.shields.io/badge/IA-ML-green)]() [![Demo](https://img.shields.io/badge/Demo-Interativa-orange)]()

## 📊 Resultados-chave (KPIs)
**< 5%** Erro · **monitor.** Talhões · **colheita** Antecip. · **ótimo** Planejamento

## 🧠 Tecnologias de IA
ML · Regression · Precision Agriculture

## ✨ O que faz
- Estimativa por talhão
- Fatores de manejo
- Planejamento de colheita
- Comparação histórica

## 🗄️ Fonte de dados real
[EMBRAPA + sensores](https://www.embrapa.br)

## ⚙️ Como funciona
1. **Coleta de dados reais** — integração com EMBRAPA + sensores
2. **Processamento com IA** — ML · Regression · Precision Agriculture
3. **Dashboard & insights** — KPIs, gráficos e recomendações acionáveis
4. **Ação automatizada** — alertas, predições e decisões em tempo real
